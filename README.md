# SLATE

**Every document. One place.**

SLATE is a fast, lightweight, 100% advertisement-free, offline-first Android document workspace built with Kotlin and Jetpack Compose.

---

## Features

- **PDF Viewer & Toolbox** — Smooth scrolling, zoom, search, text selection, annotations, signatures, rotate/reorder/delete/extract/merge/split/compress/print, and image export.
- **Word Documents** (`DOC`, `DOCX`, `ODT`, `RTF`, `TXT`) — Rich viewing and editing with formatting, lists, tables, images, find & replace, undo/redo, and export.
- **Spreadsheets** (`XLS`, `XLSX`, `ODS`, `CSV`) — Read-only viewing mode by default with pinch-to-zoom, multi-sheet navigation, search, and dedicated cell editing mode.
- **Presentations** (`PPT`, `PPTX`, `ODP`) — Full slide rendering, fit-to-screen, pinch-to-zoom, vertical/full-screen presentation mode, and slide editing.
- **Document Scanner & Converter** — Scan documents and convert between supported formats locally.
- **Offline-First & Private** — Zero `INTERNET` permissions, no ads, no subscriptions, no trackers, and no account required.

---

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Storage & Persistence:** Room, DataStore Preferences
- **Document Processing:** PDFBox-Android, ML Kit Document Scanner, custom OOXML/ODF/CFB codecs
